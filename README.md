# ☕ Bhakti's Cafe

Welcome to **Bhakti's Cafe** – a simple and attractive web-based cafe website where customers can explore different food and beverage items and place orders.

## 📌 About the Project

Bhakti's Cafe is a frontend web project designed to provide a smooth and user-friendly online cafe experience.

The website contains different food categories such as **Veg, Non-Veg, Drinks, and Desserts**, allowing customers to browse the menu and select their favorite items.

## ✨ Features

- 🏠 Attractive cafe homepage
- 🍕 Food and beverage menu
- 🥗 Veg food category
- 🍗 Non-Veg food category
- 🥤 Drinks category
- 🍰 Desserts category
- 🛒 Add items to order
- 📋 View and manage orders
- 💻 Simple and user-friendly interface
- 📱 Responsive design

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Website functionality and interactions
